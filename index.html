작은 팀, 얼음처럼 매끄러운 게임

유행하는 장르를 빠르게 연구하고, 메커니즘은 배우되 아트·사운드·이름은 전부 새로 만듭니다. 가벼운 네이티브 빌드로 어떤 기기에서든 부드럽게 돌아가는 게임이 목표입니다.

가볍고 빠르게

가벼운 네이티브 빌드로 iOS · Android · macOS · Windows · Linux · 웹까지 하나의 코드로 대응합니다.

100% 오리지널 에셋

모든 게임의 아트와 사운드, 이름을 직접 제작합니다. 절차 생성과 AI 파이프라인을 적극 활용해 작은 팀의 속도를 냅니다.

빠른 실험, 넓은 장르

퍼즐, 디펜스, 카드, 방치형, 서바이벌 — 장르를 가리지 않고 프로토타입에서 출시까지 짧은 주기로 달립니다.
